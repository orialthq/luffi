# 정의

사용자가 저장한 맛집 중 이번에 실제로 갈 곳을 결정하려는 한 번의 식사 상황.

식당의 고정 속성이 아니라 결정이 필요한 순간마다 새로 생기는 정보다.

# 필수 정보

- 먹을 지역
- 날짜와 시간

# 필요할 때만 받는 정보

- 동행 인원
- 예산
- 식사 목적
- 알레르기·식단
- 이동 가능 거리

# 입력 예시

> 금요일 저녁 7시, 성수, 2명

> 오늘 점심, 강남역, 혼자

> 토요일 저녁, 합정, 친구 4명, 1인 3만원 이하

# 입력 원칙

- 처음부터 모든 조건을 묻지 않는다.
- 지역과 시간만 먼저 받는다.
- 후보를 좁히는 데 필요할 때만 추가 질문한다.
- 데이트·회식 같은 목적을 식당의 절대적 속성으로 저장하지 않는다.

# MVP에서의 역할

저장된 식당 지점 중 이번에 실제로 갈 수 있는 후보를 거르는 기준이 된다.

# 확인할 가설

사용자는 복잡한 필터 대신 식사 상황을 한 문장으로 입력할 수 있다.
