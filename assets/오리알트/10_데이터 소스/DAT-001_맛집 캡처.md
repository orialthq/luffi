# 정의

사용자가 SNS에서 발견한 맛집 정보를 캡처한 이미지.

# 얻는 방식

- SNS 공유 시트로 앱에 전달
- 갤러리에서 사용자가 직접 선택
- 여러 이미지를 한 번에 선택해 가져오기

# 이미지에서 얻을 수 있는 정보

- 식당명과 지점 후보
- 지역과 주소
- 대표 메뉴
- 보이는 가격
- 게시물 본문과 화면 자막
- 원본 계정과 URL
- 광고·협찬 표기
- 캡처한 시각

# 이미지로 알 수 없는 정보

- 사용자가 저장한 정확한 이유
- 현재 영업 여부
- 실제 예약 가능 여부
- 사용자가 실제로 방문했는지
- 데이트·회식 등에 적합한지

# MVP에서의 역할

맛집 캡처를 정확한 실제 장소와 연결하기 위한 최초 입력 데이터다.

# 확인할 가설

사용자는 결과가 즉시 유용하다면 맛집 캡처 5장 이상을 직접 선택해 맡긴다.
