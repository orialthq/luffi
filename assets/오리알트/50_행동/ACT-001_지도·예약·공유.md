# 정의

추천받은 식당을 실제 방문으로 이어가기 위해 사용자가 바로 실행할 수 있는 행동 묶음이다.

# 제공할 행동

## 지도에서 보기

- 네이버 지도
- 카카오맵
- 구글 지도

한국 사용자를 기준으로 네이버 지도, 카카오맵, 구글 지도 순서로 보여준다.

## 길찾기

사용자의 현재 위치 또는 직접 입력한 출발지에서 식당까지 이동 경로를 연다.

## 예약하기

예약 링크가 확인된 식당만 제공한다.

예약 가능 여부가 불확실하면 가능한 것처럼 표시하지 않는다.

## 공유하기

선택한 식당과 선택 이유를 동행자에게 전달한다.

공유받는 사람은 앱이 없어도 식당명·시간·위치·지도 링크를 확인할 수 있어야 한다.

# 기록할 행동 신호

- 어떤 식당을 선택했는지
- 어떤 지도 서비스를 열었는지
- 길찾기를 시작했는지
- 예약 화면을 열었는지
- 동행자에게 공유했는지
- 추천을 거절하고 다른 후보를 봤는지

# 해석 원칙

- 지도 열기는 방문 완료가 아니다.
- 예약 화면 열기는 예약 완료가 아니다.
- 공유는 관심 신호지만 방문 증거는 아니다.
- 각 행동의 강도를 구분해 기록한다.

# MVP에서의 역할

추천을 보여주는 데서 끝내지 않고 사용자가 길찾기·예약·공유를 즉시 실행하게 한다.

# 확인할 가설

식사 상황에 맞는 한 곳을 먼저 제시하면 사용자의 40% 이상이 지도·길찾기·예약·공유 중 하나를 실행한다.
