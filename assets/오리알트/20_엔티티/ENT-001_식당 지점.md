# 정의

사용자가 실제로 방문할 수 있는 하나의 물리적 식당 지점.

브랜드와 지점은 구분한다.

- `스타벅스`는 브랜드
- `스타벅스 성수역점`은 식당 지점

# 식별에 필요한 정보

- 정규화된 식당명
- 지점명
- 도로명 주소
- 좌표
- 전화번호
- 카카오 지도 장소 ID
- 네이버 지도 장소 ID
- 구글 지도 장소 ID

# 연결되는 정보

- 원본 맛집 캡처
- 대표 메뉴
- 보이는 가격
- 지역
- 사용자가 저장한 시각
- 사용자의 방문 상태
- 지도·예약 링크

# 동일 장소 판단 규칙

1. 지도 장소 ID가 같으면 동일 지점으로 판단한다.
2. 전화번호와 주소가 같으면 동일 지점일 가능성이 높다.
3. 식당명과 정확한 주소가 같으면 동일 지점으로 합친다.
4. 이름만 같으면 자동으로 합치지 않는다.
5. 지점이 여러 개라면 사용자에게 후보를 보여준다.

# 중복 캡처 처리

같은 식당을 여러 번 캡처한 것은 삭제할 중복이 아니다.

하나의 식당 지점에 여러 캡처를 연결하고, 반복해서 저장했다는 사실을 관심 신호로 남긴다.

# MVP에서의 역할

맛집 캡처를 지도·길찾기·예약으로 연결할 수 있는 실제 장소로 변환한다.

# 확인할 가설

맛집 캡처의 85% 이상을 사용자의 추가 입력 없이 정확한 식당 지점과 연결할 수 있다.
