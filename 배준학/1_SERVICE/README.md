# Luffi — 서비스 소개

> 근거: 사업계획서(2026-09-16), 모두의 창업 2기 지원서(2026-09-17), 펀딩 소개 스토리 v64
> 구현할 기능은 [`FEATURES.md`](FEATURES.md)에 따로 정리했습니다.

## 한 줄 정의

**저장한 정보를 개인의 맥락과 연결해, 필요한 일을 제안하고 완료까지 돕는 모바일 AI Agent.**
"캡처를, 다음 행동으로." — *Turn saved inspiration into real-life experiences.*

## 문제

- **저장은 하지만 다시 꺼내 쓰지 않는다.** SNS에서 본 맛집·레시피·뷰티 팁·숙소를 캡처해 두지만, 막상 필요할 때 찾지 못하거나 처음부터 다시 검색한다.
- **하고 싶은 일을 정해도 실행 계획은 직접 짜야 한다.** 자료를 비교하고, 할 일과 순서를 정하고, 진행 상황을 챙기는 수고가 사용자에게 남는다.
- **기존 AI 도구도** 자료와 조건을 사용자가 직접 전달하고, 바뀐 내용을 반복해서 설명해야 한다.

## 고객

SNS·웹에서 정보를 자주 캡처하고, 그 정보를 실제 생활(방문·구매·요리·여행 준비)에 쓰고 싶은 모바일 사용자.
초기에는 **맛집·뷰티·패션**에 집중하고, 여행·요리·학습·취미로 넓힌다.

## 서비스 구조

```
초기 설정(관심사·생활 패턴) → 캡처 → ① Second Brain → ② 활동 제안·계획 → ③ TaskBoard
                                        ↑                                        │
                                        └─────── 선택·수정·완료를 다시 반영 ─────────┘
```

| 구성 | 한 줄 설명 |
|---|---|
| **① Second Brain** | 캡처 속 장소·제품·방법을 추출해 관심사·목적·선택·진행 상태와 그래프로 연결하는 개인 지식 공간 |
| **② Intent Inference & Plan** | 저장한 정보와 맥락으로 필요한 활동을 추론해 제안하고, 할 일과 실행 순서를 구성 |
| **③ TaskBoard** | 할 일마다 필요한 자료를 붙여 비교·선택·실행을 돕고, 진행에 맞춰 다음 행동을 안내 |
| **보조** | 그래프 시각화, 공유 카드, 공동 TaskBoard → 장기적으로 "AI 시대의 SNS" |

## 차별점

- **캡처하는 것만으로** 정보 추출과 맥락 연결이 이어진다. 별도 전송·설명·태그가 필요 없다.
- 정보 입력 → 활동 구성 → 진행 갱신이 **사용자의 평소 행동에서 끊기지 않고** 이어진다.
- 쓸수록 쌓이는 조건·선택·수정 기록이 **다음 활동의 준비를 줄인다.**
