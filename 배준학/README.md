# 배준학 폴더

Luffi를 **차근차근, 확실하게** 만들기 위한 계획과 그 근거를 모아 둔 곳입니다.

| 파일 | 내용 |
|---|---|
| [`SERVICE.md`](SERVICE.md) | Luffi가 무엇인지 (한 장) |
| [`PLAN.md`](PLAN.md) | **단계별 개발 계획** — 같이 채워 가는 문서 |
| [`research/`](research/README.md) | 참고 자료: 경쟁 제품 조사, 기술 조사 |

처음이라면 `SERVICE.md` → `PLAN.md` 순서로 읽으면 됩니다. `research/`는 근거가 궁금할 때만 열어 보세요.
