Luffi 서비스 정의와 조사 자료를 모아 두는 곳입니다.

- 이 폴더의 문서는 **서비스 정리와 연구 자료**입니다. 작업 지시나 팀 결정이 아닙니다.
- 제품 코드와 공식 문서는 기존 위치(`lib/`, `server/`, `docs/`)에 그대로 있습니다.
