## 평가 방법 (Luffi가 가져올 것)

- **지표를 쪼갭니다:** 기억 정확도, 검색 정밀도·재현율, 답 품질, 지연·비용. "유령 기억" 충돌 정확도도 따로 봅니다.
- **여러 시점(주·월·분기)에서** 평가합니다. 정답은 사실을 먼저 만들고 문장을 나중에 렌더링해 구성상 정확하게 만듭니다.
- **먼저 제안하기**는 트리거 정밀도, 타이밍, 보정, 사용자 부담, 올바른 침묵으로 채점합니다.
- **위험 측정:** 오래된 사실 사용, 철회된 기억 재사용, 누출. 결정적 추적으로 판정하고 LLM 심판은 쓰지 않습니다.
- **공정 비교:** Agent Memory Leaderboard 하네스(답변 모델·프롬프트·top-k 고정)
